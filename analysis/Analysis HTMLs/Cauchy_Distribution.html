2. Theoretical Mean and Standard Deviation

  • Theoretical Mean (\(\mu\)): Undefined (NA)[cite: 2]
  • Theoretical Standard Deviation (\(\sigma\)): Undefined (NA)[cite: 2]

For a standard Cauchy distribution, the PDF is:

\[f(x) = \frac{1}{\pi(1 + x^2)}\]

The theoretical mean is undefined because the integral does not absolutely converge:

\[\int_{-\infty}^{\infty} x \frac{1}{\pi(1 + x^2)} \, dx \to \text{Undefined}\]

Since the mean is undefined, the variance and theoretical standard deviation are also undefined, representing an infinitely heavy tail.

6. Evidence for Normality

Graphical Evidence (Density & Q-Q Plots)

Code 
library(ggplot2)
library(dplyr)
library(patchwork)

set.seed(8676)

B <- 10000L
selected_n <- c(1, 10, 30, 100)

density_qq_list <- list()

for (n_val in selected_n) {
  observations <- rcauchy(B * n_val, location = 0, scale = 1)
  sample_matrix <- matrix(observations, nrow = B, ncol = n_val)
  means <- rowMeans(sample_matrix)
  
  sim_mean <- mean(means)
  sim_se <- sd(means)
  
  z_means <- if (is.finite(sim_se) && sim_se > 0) (means - sim_mean) / sim_se else rep(NA_real_, B)
  density_qq_list[[length(density_qq_list) + 1]] <- data.frame(
    n_label = paste0("n = ", n_val),
    n_num = n_val,
    z = z_means
  )
}

plot_data <- bind_rows(density_qq_list) %>% filter(is.finite(z))
plot_data$n_label <- factor(plot_data$n_label, levels = paste0("n = ", selected_n))

tight_theme <- theme_bw(base_size = 11) +
  theme(
    plot.title = element_text(size = 12, face = "bold", hjust = 0.5),
    strip.text = element_text(size = 10, face = "bold"),
    plot.margin = margin(t = 4, r = 6, b = 4, l = 6)
  )

p_dens_tight <- ggplot(plot_data, aes(x = z)) +
  geom_density(fill = "#E69F00", alpha = 0.35, color = "#E69F00", linewidth = 0.6) +
  stat_function(fun = dnorm, args = list(mean = 0, sd = 1), linetype = "dashed", color = "black") +
  facet_wrap(~ n_label, nrow = 2, scales = "free_y") +
  labs(title = "Empirical Density vs N(0,1)", x = "Standardized Mean (Z)", y = "Density") +
  tight_theme

p_qq_tight <- ggplot(plot_data, aes(sample = z)) +
  geom_abline(intercept = 0, slope = 1, linetype = "dashed", color = "gray30") +
  stat_qq(color = "#E69F00", alpha = 0.15, size = 0.8) +
  facet_wrap(~ n_label, nrow = 2) +
  labs(title = "Normal Q-Q Plots", x = "Theoretical Quantiles", y = "Sample Quantiles") +
  tight_theme

7. Limitations and Surprises

  • Key Observations / Surprises: There is no skewness but the heavy tailed nature of the Cauchy distribution makes it impossible to converge. Even though it is a common distribution it does not appear to follow the typical rules of other distributions. I am surprised that it never converges, and actually the excess kurtosis grows rapidly as sample sizes get larger. It clearly does not adhere to the Central Limit Theorem.
  • Simulation Limitations: Monte Carlo simulation has a large effect on this distribution as seen in the skewness which does not converge. It appears that the skewness converges at first glance but the values are so high that it does not. Other distributions converge to zero meaning there is extremely small chance that some extremely high outlier occur but that is not the case with the Cauchy.

8. Final Verdict

Central Limit Theorem Does Not Apply

The Central Limit Theorem does not apply to this distribution. There were some warning signs based on the inability to calculate theoretical standard error and mean. In practice the possibility of outliers presents itself very strongly and makes convergence impossible. There is no smoothing that occurs because the heavy tails will always win and skew the model.
