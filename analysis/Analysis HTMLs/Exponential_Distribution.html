1. Original Population Distribution

  • Name / Class: Exponential
  • Type: Continuous, heavily right-skewed
  • Description: The exponential distribution is a distribution representing the occurrence of an event that will. happen on average once per unit of time. These events happen continuously and independently. An example used in class would be how late a professor is to class.

2. Theoretical Mean and Standard Deviation

  • Theoretical Mean (\(\mu\)): 1[cite: 4]
  • Theoretical Standard Deviation (\(\sigma\)): 1[cite: 4]

For an Exponential distribution \(X \sim \text{Exp}(\lambda)\) with rate parameter \(\lambda = 1\), the PDF is:

\[f(x) = \lambda e^{-\lambda x}\]

The theoretical mean is calculated as:

\[\mu = \text{E}[X] = \frac{1}{\lambda} = 1\]

The theoretical standard deviation is derived from the variance:

\[\sigma = \sqrt{\text{Var}(X)} = \sqrt{\frac{1}{\lambda^2}} = 1\]

6. Evidence for Normality

Graphical Evidence (Density & Q-Q Plots)

Code 
library(ggplot2)
library(dplyr)
library(patchwork)

set.seed(8676)

B <- 10000L
selected_n <- c(1, 20, 30, 35)

density_qq_list <- list()

for (n_val in selected_n) {
  observations <- rexp(B * n_val, rate = 1)
  sample_matrix <- matrix(observations, nrow = B, ncol = n_val)
  means <- rowMeans(sample_matrix)
  
  sim_mean <- mean(means)
  sim_se <- sd(means)
  
  z_means <- if (is.finite(sim_se) && sim_se > 0) (means - sim_mean) / sim_se else rep(NA_real_, B)
  density_qq_list[[length(density_qq_list) + 1]] <- data.frame(
    n_label = paste0("n = ", n_val),
    n_num = n_val,
    z = z_means
  )
}

plot_data <- bind_rows(density_qq_list) %>% filter(is.finite(z))
plot_data$n_label <- factor(plot_data$n_label, levels = paste0("n = ", selected_n))

tight_theme <- theme_bw(base_size = 11) +
  theme(
    plot.title = element_text(size = 12, face = "bold", hjust = 0.5),
    strip.text = element_text(size = 10, face = "bold"),
    plot.margin = margin(t = 4, r = 6, b = 4, l = 6)
  )

p_dens_tight <- ggplot(plot_data, aes(x = z)) +
  geom_density(fill = "#009E73", alpha = 0.35, color = "#009E73", linewidth = 0.6) +
  stat_function(fun = dnorm, args = list(mean = 0, sd = 1), linetype = "dashed", color = "black") +
  facet_wrap(~ n_label, nrow = 2, scales = "free_y") +
  labs(title = "Empirical Density vs N(0,1)", x = "Standardized Mean (Z)", y = "Density") +
  tight_theme

p_qq_tight <- ggplot(plot_data, aes(sample = z)) +
  geom_abline(intercept = 0, slope = 1, linetype = "dashed", color = "gray30") +
  stat_qq(color = "#009E73", alpha = 0.15, size = 0.8) +
  facet_wrap(~ n_label, nrow = 2) +
  labs(title = "Normal Q-Q Plots", x = "Theoretical Quantiles", y = "Sample Quantiles") +
  tight_theme

p_dens_tight | p_qq_tight
  • Density Overlays: The density overlay charts show that due to the extreme right skewness of the exponential distribution, the sample mean distributions have a hard time shaking off the skewness that is left over. I think that by n = 30, the skewness settles down to an acceptable level. There is still some skewness but visually the n = 30 graph falls into the standard distribution well.
  • Q-Q Plot Quantile Alignment: The Q-Q plots approach linearity rather slowly. Interestingly the Q-Q plot for n = 35 appears less linear than 30 which is probably due to the randomness in the Monte Carlo simulation instead of something within the distribution. The linearity feels comfortable at the n = 30 mark although there is not much difference from n = 25.

That being said, the W score for this distribution approaches 1 rather quickly meaning that it fits the normal distribution relatively well from n = 5 and beyond.

7. Limitations and Surprises

  • Key Observations / Surprises: There was a persistent skewness to the graph and I noticed across simulations there was not a very smooth graph peak until large sample sizes.
  • Simulation Limitations: I noticed the Monte Carlo simulation results affected the graph quite a bit resulting in high levels of visual variance between small sample size changes such as n = 30 and n = 31.

8. Final Verdict

Central Limit Theorem Confirmed at n = 30

I felt like the graphs tell the story here, the Shapiro Wilk W value approaches 1 fairly quickly and the main reasons for waiting until n = 30 were mostly due to the excess skewness that hung on throughout the graphs.
