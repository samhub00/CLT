2. Theoretical Mean and Standard Deviation

  • Theoretical Mean (\(\mu\)): 0.5[cite: 5]
  • Theoretical Standard Deviation (\(\sigma\)): 0.6708[cite: 5]

For a Binomial distribution bounded by the number of trials \(n_{\text{size}} = 5\) and probability \(p = 0.10\), the PMF is:

\[P(X = k) = \binom{n_{\text{size}}}{k} p^k (1-p)^{n_{\text{size}}-k}\]

The theoretical mean is calculated as:

\[\mu = n_{\text{size}} \cdot p = 5(0.10) = 0.5\]

The theoretical standard deviation is derived from the variance:

\[\sigma = \sqrt{n_{\text{size}} \cdot p \cdot (1-p)} = \sqrt{5(0.10)(0.90)} = \sqrt{0.45} \approx 0.6708\]

6. Evidence for Normality

Graphical Evidence (Density & Q-Q Plots)

Code 
library(ggplot2)
library(dplyr)
library(patchwork)

set.seed(8676)

B <- 10000L
selected_n <- c(1, 10, 20, 25)
binom_size <- 5L
binom_prob <- 0.10

density_qq_list <- list()

for (n_val in selected_n) {
  observations <- rbinom(B * n_val, size = binom_size, prob = binom_prob)
  sample_matrix <- matrix(observations, nrow = B, ncol = n_val)
  means <- rowMeans(sample_matrix)
  
  sim_mean <- mean(means)
  sim_se <- sd(means)
  
  z_means <- if (is.finite(sim_se) && sim_se > 0) (means - sim_mean) / sim_se else rep(NA_real_, B)
  density_qq_list[[length(density_qq_list) + 1]] <- data.frame(
    n_label = paste0("n = ", n_val),
    n_num = n_val,
    z = z_means
  )
}

plot_data <- bind_rows(density_qq_list) %>% filter(is.finite(z))
plot_data$n_label <- factor(plot_data$n_label, levels = paste0("n = ", selected_n))

tight_theme <- theme_bw(base_size = 11) +
  theme(
    plot.title = element_text(size = 12, face = "bold", hjust = 0.5),
    strip.text = element_text(size = 10, face = "bold"),
    plot.margin = margin(t = 4, r = 6, b = 4, l = 6)
  )

p_dens_tight <- ggplot(plot_data, aes(x = z)) +
  geom_density(fill = "#CC79A7", alpha = 0.35, color = "#CC79A7", linewidth = 0.6) +
  stat_function(fun = dnorm, args = list(mean = 0, sd = 1), linetype = "dashed", color = "black") +
  facet_wrap(~ n_label, nrow = 2, scales = "free_y") +
  labs(title = "Empirical Density vs N(0,1)", x = "Standardized Mean (Z)", y = "Density") +
  tight_theme

p_qq_tight <- ggplot(plot_data, aes(sample = z)) +
  geom_abline(intercept = 0, slope = 1, linetype = "dashed", color = "gray30") +
  stat_qq(color = "#CC79A7", alpha = 0.15, size = 0.8) +
  facet_wrap(~ n_label, nrow = 2) +
  labs(title = "Normal Q-Q Plots", x = "Theoretical Quantiles", y = "Sample Quantiles") +
  tight_theme

p_dens_tight | p_qq_tight
  • Density Overlays: As seen in the density charts, the discrete nature of the graph forces many peaks through the distribution. As the sample size increases we can start to see the graph become smoother. There is quite a large difference between n = 24 and n = 25 visually.
  • Q-Q Plot Quantile Alignment: While there are steps due to the discrete nature of the binomial distribution, the Q-Q plots are linear enough through the sample sizes.

Statistical Evidence (Shapiro-Wilk Test & Moment Ratios)

Code 
summary_table %>%
  select(n, skewness, excess_kurtosis, shapiro_W, shapiro_p) %>%
  kable(col.names = c("n", "Skewness", "Excess Kurtosis", "Shapiro-Wilk W", "p-value")) %>%
  kable_styling(bootstrap_options = c("striped", "hover", "condensed"))
  • Conclusion on Normality: Statistically we can see the decrease in skewness from a starting value of 1.188 (n = 1) to 0.203 at (n = 25). Kurtosis stays relatively stable around 0 after the first couple sampling size increases. The Shapiro-Wilk W value also approaches 1 very quickly indicating that the practical shape of the distribution is becoming normal. The reason this is not reflected in the p-value is because the binomials discrete nature creates micro-steps that only start to smooth when the sample size reaches very large amounts. The sample size n = 25 is when these three values start to align, skewness decreases, kurtosis stays normal and while the W value in my simulation actually decreases it still remains around 1.

7. Limitations and Surprises

  • Key Observations / Surprises: The key observation I noticed was the affect the discrete nature of the binomial distribution had on the sample means. The sample distribution remained very peaked until sample sizes started to get into the 20’s.
  • Simulation Limitations: I noticed with some experimentation that the lower Monte Carlo reps generated smoother graphs, and that larger rep sizes generated graphs that remained pointed throughout the sample size increases.

8. Final Verdict

Central Limit Theorem Confirmed at n = 25

The binomial distribution presents an interesting challenge because the Shapiro-Wilk statistic approaches 1 rapidly indicating a normal distribution shape but visually this is not confirmed until around n = 25. The decision to choose n = 25 over n = 20 was purely because of the peaks still being very visible as well as the skewness value indicating a right skew.
