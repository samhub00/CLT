# CLT
### Beyond the Bell Curve: Evaluating Central Limit Theorem Convergence
#### By: Sam Hubler

### Goal
The goal of this project is to test and verify Central Limit Theorem on different known distributions.
Each known distribution will be given an approximate normalization sample size (n). In order to generate this number
there will be a variety of methods for statistical verification not limited to skewness, kurtosis, simulated mean, and plots 
like the Q-Q plot.  

### Distributions Tested
- Standard Normal `rnorm()`
- Six Sided Die `sample()`
- Exponential `exp()`
- R-Binomial `rbinom()`
- Cauchy `rcauchy()`

### Bonus Distributions
- Dependent Machine Failure
- Non-Identical Bernoulli
- Population Death Distribution
